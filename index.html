How these tags are used
  • Google search results use <title> and meta description for the result snippet.
  • Facebook, WhatsApp, iMessage, Slack, Discord, LinkedIn read Open Graph tags (og:title, og:description, og:image, og:url, og:type, og:site_name) to build link previews.
  • X / Twitter prefers twitter:card, twitter:title, twitter:description, twitter:image, and falls back to Open Graph when they're absent.
  • Canonical URL tells search engines which URL is the authoritative version of the page.
  • Favicon shows in browser tabs and bookmarks.
  • Charset, viewport, html lang are basic correctness signals for rendering and accessibility.
